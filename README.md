
# Online Voting System - Core Java

## Project Description
A college election system where students can
register, log in and cast their votes digitally.

Each student can vote only once.

## Features
- Student Registration and Login
- Candidate List
- Vote Casting
- One Student - One Vote
- View Total Votes
- Automatic Winner Calculation
- Runner-Up Display

## Technologies Used
- Core Java
- OOP Concepts
- HashMap
- Collections Framework
- Exception Handling

## How to Run
1. Download Main.java
2. Open in a Java IDE.
3. Compile Main.java.
4. Run the Main class.
